## [0.1.0] - 2026-11-22

First public release.

### Added
- The `cold-start-brief` skill with five variants: new kickoff, optimize an existing prompt, repair or refresh, facts-only second opinion, and research.
- A fetch of the target model's current official prompting guide on every run, with short dated notes on what to look for.
- An optional private profile at `~/.claude/cold-start-brief-profile.md`, and an invented example of one.
- A plugin manifest and a marketplace manifest, so the repo installs as its own marketplace.
- An invented sample project and a sample handoff written for it.
